# App routes

Next.js 15 App Router with React 19, TypeScript and Tailwind CSS. `page.tsx` is the home page; `projects/[slug]/page.tsx` renders the typed project model and case-study bodies. `layout.tsx` supplies fonts, navigation, footer and site metadata. `opengraph-image.tsx` and `icon.svg` provide sharing artwork and the favicon.

Run `npm run dev` from the repository root. Rebuild log data with `npm run data`. See the root `README.md` for data/model replacement and `CLAUDE.md` for design rules.
